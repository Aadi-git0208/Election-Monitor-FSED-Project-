# VoteGuard - Election Monitoring System

## Project Overview

VoteGuard is a web-based Election Monitoring System designed to ensure transparency, efficiency, and security in the election process.
It helps administrators monitor elections, manage voters, track voting activity, and analyze results in real time.

## Features

* Voter Registration and Management
* Secure Voting System
* Real-time Election Monitoring
* Result Analysis and Visualization
* Authentication and Authorization (Admin/User)
* User-friendly Interface

## Tech Stack

## Installation and Setup

### Backend (Spring Boot)

1. Open project in IntelliJ or Eclipse
2. Configure MySQL database in application.properties
3. Run the Spring Boot application

### Frontend (React Vite)

cd frontend
npm install
npm run dev

## API Testing

Use Postman to test backend APIs such as:

* GET /students (or your APIs)
* POST /add
* PUT /update
* DELETE /delete
